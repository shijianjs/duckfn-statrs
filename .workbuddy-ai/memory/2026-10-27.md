## 补充：有副作用标量函数与 `volatile`（来自 duckfn_open）

提交 `409c189`（模板仓库 main），补进同一批 AGENTS 文件：

- 不标 `volatile = true` 的后果：常量折叠发生在**优化期**，折进 `length(...)` 后执行期再求值一次
  （`SELECT length(op_write_file('a','txt'))` 落两个文件、`op_print` 打两遍）；`EXPLAIN` 会真的执行，
  产生副作用。
- 标上之后语义是「一次调用 = 一行」，常量参数也逐行；代价是不能承诺「常量只跑一次」，
  文档/README/`description.yml` 都要按逐行写；纯函数不要加。
- 实现约定：返回值带上入参（文本进文本出、内容进路径出）、stdout 要 flush（按行缓冲）、
  不承诺逐行副作用的顺序。
- 测试的四类可数断言：`duckdb_functions().has_side_effects` 名单、文件计数（求值次数）、
  `EXPLAIN` 后目录为 0 文件、常量参数三行三个文件；不要断言 stdout 内容与顺序。

## 补充：文档站展示图像（来自 duckfn_kuva）

提交 `e348517`（模板仓库 main）：

- 两条路径：扩展算出来的图（返回值是 SVG/HTML）用可运行块 + `show` 渲染；站点静态图放
  `docs/static/img/`，引用走 `useBaseUrl('img/…')`，不要写死 `/<repo>/img/…`。
- `show` 取值：`table`（默认）/ `text` / `html` / `iframe` / `svg`。SVG 图用 `svg`（可全屏缩放），
  交互内容必须 `iframe`（沙箱、自己的坐标系）且手调高度。
- 三条不要：钉画布 `width`/`height`、给 `svg` 块加 `option.height`、给块能画出来的图再配 `<img>` 截图。
- 静态图：`static/` 会复制进每个 locale（跨语言共用一份即可）；体积控制在几十 KB；换 logo 时
  logo / favicon / 社交卡片 / `custom.css` 品牌色一起换。
